correct expansions. Apply the casing exactly as shown, even inside all-caps text. See
`editing-standards.md` §1.1 for how to format the *first use* of an acronym in content. Some acronyms
below are trademarks/registered trademarks — pair with the correct approved noun where applicable
(see `editing-standards.md` §1.10).
